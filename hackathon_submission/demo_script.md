# SkillForge AI - Demo Video Script

Hi, I’m presenting SkillForge AI, an agentic AI career assistant built for AMD AI DevMaster Hackathon Track 2. In this demo, I will show how the app helps learners create profiles, analyze career direction, generate roadmaps, and get project recommendations.

## 1:00 - Profile Creation

I’ll begin by explaining the demo user profile and the information captured: name, skills, career goal, and interests. This profile is the foundation for personalized guidance and helps the AI understand the learner’s background.

## 2:00 - Dashboard Analysis

Next, I’ll show the chat dashboard and explain how SkillForge AI stores conversation history. I’ll highlight how the system can recall user context and use it to provide tailored suggestions.

## 3:00 - AI Assistant Demonstration

Then I’ll engage the AI assistant with questions like “Suggest projects” and “What roadmap should I follow?” The app responds with career-specific guidance, skill gap advice, and practical next steps.

## 4:00 - Project Conclusion

Finally, I’ll summarize the value of SkillForge AI: personalized career guidance, roadmap generation, project recommendations, and future ROCm optimization for local AI agent deployment. I’ll close with the next steps for expanding the platform.
